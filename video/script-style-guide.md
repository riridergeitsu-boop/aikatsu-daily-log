# 動画台本スタイルガイド（いちず）

アイカツ情報まとめのショート動画（縦型・1〜2分）の台本の書き方。
過去の台本8本の分析をもとにまとめたもの。新しい台本を書くときはこの型と口調に合わせる。

---

## 1. 全体の構成

```
① つかみ：一言の見出し          「レアカード来た！！」「10月8日に、アイカツ復活！」
② 定型の導入                    「〇〇が（大量）発表されたので見ていく！」
③ 本編：その１・その２（・その３）  1本あたり2〜3項目。1項目だけのときは「その〜」なし
④ 「他にも〜」で残りをまとめる     詳しく話さない情報は1文で済ませ、「公式ページをチェックしてね」
⑤ 締め：「てな訳で、以上です！」
⑥ おまけ：「ちなみに〜」「そんなことより〜」「ちょっと話は変わって〜」
   個人的な話・続報・ボケを入れて終わる
```

- **⑥が本編の後にある**のが一番の特徴。「以上です」の後に、本当に言いたい話や笑いどころを置く。
  （例：有給を取った話、筐体が見つからない話、分身の術、「入学してこようと思います」）
- 長さは1本1〜2分。1項目は「事実 → 感想 → 推しの話」の3〜5文くらい。

## 2. 各項目の中の流れ

1. **事実**：「なんと！〇〇が公開されました！」
2. **補足**：枚数、種類、価格、日付などの具体的な数字
3. **感想**：「激アツ！」「うれしすぎる！」「夢すぎる！」
4. **自分の推し**：「ちなみにいちずは、〇〇が推しなので、このカードがめちゃめちゃほしい！」
5. **（あれば）引っかかる点やツッコミ**：「あれ…？」「多すぎる！」「お金かかるじゃん！」

## 3. 話し手のキャラ設定（いちず）

- 一人称は「いちず」
- **社会人**で、平日の稼働日はつらい（有給、「そもそも平日やめて」）
- 推し
  - **オデットスワンコーデが最推し**（「欲しすぎてメツ！」）
  - オーロラキスコーデ（「親の顔より見た」）
  - ドリーミークラウン、プレミアムスクールドレス、蘭ちゃん
- 初代アイカツのことをよく知っている（ローズボンボンの収録弾の予想、旧カードとの比較、昔のサイトとの比較）
- 公式には「アイカツ公式さん」「アイカツさん」と呼びかける。愛情を込めつつ軽くツッコむ

## 4. よく出る言い回し

| 種類 | 例 |
|---|---|
| 導入 | 「発表されたので見ていく！」「なんと！」「ついに！」「またまた」 |
| 盛り上げ | 「激アツ」「〜すぎる！」「めちゃめちゃ」「夢すぎる」「念願！念願の！」 |
| 欲しい | 「めちゃめちゃほしい！」「コンプしたい！」「欲しすぎてメツ！」 |
| 数への反応 | 「なんと〇〇枚！」「多すぎる！」「え待ってめっちゃ少なくない？」 |
| 疑問・ボケ | 「あれ…？」「あれ？？？？」「？？？？？」「〜では…？」 |
| 自分へのツッコミ | 「（？）」「（語彙）」「（あくまでいちずの予想）」「※ムリ」 |
| 締め | 「てな訳で、以上です！」 |
| おまけへの切り替え | 「ちなみに、」「そんなことより、」「ちょっと話は変わって、」「実は〜続報がありまして」 |

## 5. 笑いを取る型

- **天丼（同じボケの繰り返し）**：「？？？？？」を2回入れ、もう一度読み直す
- **言葉なしのオチ**：「！！！！！」「😭」「・・・」などを画面だけで見せる
- **ありえない解決策**：「分身すればいい」「入学してこようと思います」「機種変しようかな」＋「（？）」
- **すぐ手のひら返し**：「お金かかるじゃん！」→「いっぱい遊べてうれしい！」
- **台本の中のツッコミ**：「（もっと親のオーロラキスコーデ見て）」「（ありがとう弊社）」のように、カッコの中で自分に返す
- **数字のオチ**：あるはずのものが0枚 →「あれ？？？？」

## 6. 台本に書く演出メモ

- `（〇〇を順に見ていく）` `（めっちゃキラキラしてる）` のように、**カッコ書きを画面の指示**として使う。
  - 例：カードを1枚ずつ見せる、タイプ別（キュート → クール → セクシー → ポップ）に順番に並べる
- 動画を作るときは、この部分を「この区間はカードを順に出す」という指定として扱う。

## 7. 内容の傾向

- 扱う情報：公式の発表（カード公開、キャンペーン、グッズ、遊べるお店、ゲームモード）
- 毎回入れる情報：**日付・価格・枚数・店舗数**の数字
- 時期：アイカツアンコール稼働（2026/10/8）前後の情報解禁ラッシュを追いかけている

```

【〇〇】が発表されたので見ていく！

その１
【項目名】
なんと！【事実＋数字】。
【感想】！
ちなみにいちずは【推し】がめちゃめちゃほしい！

その２
【項目名】
【事実＋数字】。
（〇〇を順に見ていく）
あれ…？【ツッコミ】

他にも【残りの情報】など、たくさん出ました！

てな訳で、以上です！

ちなみに【個人的な話・続報】
【ボケ】（？）
```
